# WINDMILL – Marketing Team

Daily work, client visits, work plans, leave and GPS check-ins for the WINDMILL marketing team.

## Files
| File | What it is |
|---|---|
| `index.html` | The whole app |
| `sw.js` | Lets the app open offline and always load the newest version |
| `manifest.webmanifest` | App name and icon when installed on a phone |
| `icon-192.png`, `icon-512.png` | App icons |

## Hosting on GitHub Pages
1. Put all files in the root of the repository (not inside a folder).
2. Settings → Pages → Source: **Deploy from a branch** → Branch **main** / **(root)** → Save.
3. Open the link GitHub shows (https://USERNAME.github.io/REPO/) and install it on the phone (Add to Home screen).

Data is stored in Firebase Realtime Database (`marketing-windmill-cafe`). Nothing in this repository needs to change to keep using the same data.
